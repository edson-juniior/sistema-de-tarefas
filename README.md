# Sistema de Tarefas

Este projeto foi desenvolvido como atividade acadêmica com o objetivo de criar um sistema simples de gerenciamento de usuários utilizando **Node.js**, **Express** e **MySQL**.
O sistema permite cadastrar, listar e excluir usuários através de uma interface web conectada a uma API backend.

## Tecnologias Utilizadas

* Node.js
* Express
* MySQL
* HTML
* JavaScript
* Fetch API

## Funcionalidades

O sistema permite:

* Cadastrar usuários
* Listar usuários cadastrados
* Excluir usuários
* Conectar o frontend com uma API backend
* Armazenar dados em banco de dados MySQL

## Como executar o projeto

1. Clonar o repositório

git clone https://github.com/edson.junior/sistema-de-tarefas.git

2. Instalar as dependências

npm install

3. Iniciar o servidor

node server.js

4. Abrir o sistema no navegador

Abra o arquivo:

frontend/usuarios.html

## Testando o sistema

* Cadastre um novo usuário
* Clique no botão **Atualizar lista**
* Visualize os usuários cadastrados
* Exclua usuários se necessário
